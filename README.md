# Pipeline Management Dashboard

A developer-focused CI/CD pipeline management dashboard built with React, TypeScript, Vite, and CSS.

## Features

- Pipeline health overview
- Build and deployment status tracking
- Environment visibility
- Recent deployment activity
- Success-rate and execution-time metrics
- Pipeline detail cards
- Responsive dashboard layout

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production Build

```bash
npm run build
npm run preview
```

## Project Structure

```text
src/
  App.tsx       # Dashboard UI and sample pipeline data
  main.tsx      # React entry point
  styles.css    # Responsive dashboard styling
```
